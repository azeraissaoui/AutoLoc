# AutoLoc

Système de gestion de location automobile.

## Acteurs et cas d'utilisation identifiés (Séance 1)

### Client
- Consulter le catalogue de véhicules disponibles
- Réserver un véhicule
- Consulter l'historique de ses locations
- Annuler une réservation

### Agent d'agence
- Enregistrer une nouvelle location
- Gérer le retour d'un véhicule
- Consulter la disponibilité des véhicules
- Gérer les clients (créer/modifier une fiche client)

### Responsable d'agence
- Superviser les locations de son agence
- Gérer le parc de véhicules (ajout, retrait, maintenance)
- Consulter les statistiques de l'agence
- Valider les tarifs et promotions

### Administrateur
- Gérer les comptes utilisateurs (agents, responsables)
- Gérer les agences (création, modification)
- Configurer les paramètres globaux du système
- Superviser l'ensemble de la plateforme
